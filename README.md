# StockQuantLab

Quantitative research lab for Indian stock markets. We build open-source tools for momentum strategies, backtesting, and paper trading.

## 🚀 Projects

### [nse-momentum-lab](https://github.com/StockQuantLab/nse-momentum-lab)

Local-first NSE momentum research + paper trading lab implementing the 2LYNCH strategy.

- **10+ years** of NSE data (2015-2025)
- **1,800+ symbols** with survivorship-bias-free backtesting
- **Production-ready**: Calmar 43.67, 193.9% annual returns
- NiceGUI dashboard for interactive analysis

## 📊 Focus Areas

| Area | Description |
|------|-------------|
| **Momentum Strategies** | Indian market adaptations of proven momentum systems |
| **Backtesting Engine** | VectorBT + DuckDB for fast, realistic simulations |
| **Paper Trading** | Real-time signal generation and position tracking |
| **Data Quality** | Corporate action adjustments, survivorship bias handling |

## 🛠 Tech Stack

- Python 3.14+
- DuckDB (analytics), PostgreSQL (lineage)
- NiceGUI (dashboard)
- VectorBT (backtesting)
- Docker Compose (local deployment)
